# MediTrack - Frontend Client

React.js (Vite) client built with Tailwind CSS v4, Lucide React icons, and React Router.

## Setup & Run
```bash
# Install dependencies
npm install

# Run Vite dev server with proxy to backend
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```

## Environment (.env)
```env
VITE_API_URL=/api
```
